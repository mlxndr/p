## Free and Bound

@columns cols=2
### [[Free]]
**Free** to be used as independent words on their own, can be the base/root of a compound or complex word

%%(Most bases are free – but not all!)%%
::
### [[Bound]]
Cannot exist on their own and must be **bound** to another morpheme to make a word

%%(All affixes are bound, but there are other types of bound morphemes!)%%
@end

## [[Affix]]

* Must be added to a base
* Can be prefix, suffix, or (rarely) infix
  * *love, lovely*
  * *sense, nonsense*
  * *capable, incapable, incapability*

## [[Bound Base]]

* A base which cannot stand on its own but requires some affix
* Carries lexical meaning
  * *dexterity*, \**dexter*
  * *reject*, \**ject*
  * *produce, deduce, reduce, induce*, \**duce*

## Libfixes

### A liberated affix
* a piece of an existing word breaks free and becomes a productive affix, usually a suffix
* *spectacular* → *-tacular* &emsp; *alcoholic* → *-holic*

### The term
* Arnold Zwicky, 2010: *liberated* + *affix*
* *libfix* is now itself in the Cambridge Dictionary

## Changes

@terms build
  happy + *un-* → unhappy :: ^^meaning change^^ Aj → Aj ‘negative of Aj’
  amuse + *-ment* → amusement :: ^^category change^^ V → N
  wash + *-able* → washable :: ^^meaning and category change^^ V → Aj ‘able to be Ved’

--

## Some Changes

@columns cols=2 build
### Some meaning changes
Aj → Aj ‘negative Aj’<br>*happy → unhappy*

N → N ‘place where N lives’<br>*orphan → orphanage*

V → V ‘repeat V’<br>*wash → rewash*
::
### Some category changes
V → N<br>*amuse → amusement*

V → Aj<br>*impress → impressive*

N → Aj<br>*monster → monstrous*
@end

## Restrictions on Affixes

@cards cols=3 build
:: grey icon=scroll-old
### Etymological
*-en* will attach to native bases but not Latinate bases, *-ic* will only attach to French/Latin bases
:: blue icon=folder-tree
### Categorical
*-ity* can only be added to Aj, *-ize* to N or Aj, *un-* to Aj or V
:: purple icon=waveform-path
### Phonological
*-ize* prefers N and Aj bases of two or more syllables with no primary stress on the final syllable, while *-en* (Aj → V) attaches only to bases ending in plosives, fricatives, and affricates
:: orange icon=code-merge
### Syntactic
*-able* attaches to transitive verbs
:: navy icon=head-side-brain
### Semantic
*un-* can only be added to bases not already negative in meaning
@end

## Inflection

* As well as lexeme formation, morphemes help *inflect* English
  * Signal grammatical relationships
* Comparatively rare in English
  * Nouns (3 types)
  * Verbs (5 types)
  * Adjectives/Adverbs (3 types)
  * Remember, inflection isn’t *just* morphology (eg *she/her*)
