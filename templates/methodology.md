## Methodology: Step-by-Step Process

### Research Procedure

**Step 1: Participant Recruitment**
* Contacted via institutional mailing lists
* Screening questionnaire administered
* N = 250 volunteers, 180 met inclusion criteria

**Step 2: Data Collection**
* Two-hour individual sessions
* Tasks presented in counterbalanced order
* Audio/video recording with consent

**Step 3: Transcription & Coding**
* Professional transcription service
* Independent coding by two researchers
* Inter-rater reliability κ = 0.87

**Step 4: Statistical Analysis**
* Mixed-effects regression models
* Controlling for age, education, L1 background
* α = 0.05 significance threshold

## Methodology: Experimental Design

### Between-Subjects Design

**Research Question:** Does presentation modality affect comprehension?

<div class="container">
<div class="col">

#### Group A (Control)
**N = 60**

* Text-only presentation
* Standard reading task
* Comprehension test
* Retention test (1 week)

**N = 60**

* Multimedia presentation
* Interactive engagement
* Same comprehension test
* Same retention test

## Methodology: Corpus Compilation

### Building a Specialized Corpus

```
Step 1: DESIGN
├─ Define research questions
├─ Specify corpus size target
├─ Determine representativeness criteria
└─ Establish sampling frame

Step 2: COLLECTION
├─ Identify sources (published works, archives, web)
├─ Obtain permissions/licenses
├─ Automated scraping (where appropriate)
└─ Manual selection for balance

Step 3: PROCESSING
├─ Format conversion (PDF → TXT)
├─ Encoding standardization (UTF-8)
├─ Metadata tagging (author, date, genre, etc.)
└─ Structural markup (paragraphs, headings)

Step 4: ANNOTATION
├─ Part-of-speech tagging
├─ Lemmatization
├─ Syntactic parsing (if needed)
└─ Custom annotation schemes

Step 5: VALIDATION
├─ Quality control sampling
├─ Error correction
├─ Inter-annotator agreement testing
└─ Documentation finalization
```

**Final corpus:** 10.5 million words, balanced across 8 genres

## Methodology: Grounded Theory Approach

### Iterative Data Analysis Process

<div style="font-size: 0.9em;">

**Initial Data Collection** → Interview 1-5
↓
**Open Coding** → Line-by-line analysis, initial codes
↓
**Theoretical Sampling** → Purposefully select next participants based on emerging themes
↓
**Additional Data Collection** → Interview 6-12
↓
**Axial Coding** → Connect categories, identify relationships
↓
**More Theoretical Sampling** → Target specific gaps in understanding
↓
**Final Data Collection** → Interview 13-18
↓
**Selective Coding** → Integrate categories around core concept
↓
**Theoretical Saturation** → No new insights emerging
↓
**Theory Formulation** → Articulate grounded theory

</div>

*Memo-writing continuous throughout all stages*

## Methodology: Comparative Method

### Cross-Linguistic Comparison Procedure

| Step | Language A (English) | Language B (Mandarin) | Language C (Arabic) |
|------|---------------------|----------------------|---------------------|
| **1. Sampling** | 100 native speakers | 100 native speakers | 100 native speakers |
| **2. Stimuli** | Translated materials, back-translation verified for equivalence |
| **3. Tasks** | Identical tasks administered in each language |
| **4. Scoring** | Language-independent rubric with inter-rater reliability ≥ 0.85 |
| **5. Analysis** | ANOVA with language as between-subjects factor |

**Controls:** Age, education level, bilingualism status matched across groups

## Methodology: Systematic Review Protocol

### Literature Search & Selection

**Search Strategy**
* Databases: Web of Science, PubMed, PsycINFO, Google Scholar
* Keywords: ("language acquisition" OR "L2 learning") AND ("immersion" OR "study abroad")
* Date range: 2000-2024
* Language: English

**Inclusion Criteria**
* Empirical studies (quantitative or qualitative)
* Adult learners (age 18+)
* Immersion duration ≥ 3 months
* Language proficiency outcomes measured

**Exclusion Criteria**
* Review articles or theoretical papers
* Child language acquisition studies
* Insufficient methodological detail

**Screening Process**
* Initial search: 1,847 articles
* Title/abstract screening: 312 retained
* Full-text review: 94 retained
* Final corpus: 67 studies (quality threshold met)
