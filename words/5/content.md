## Affixation

English affixes are used to create a **non-transparent** new word.

<!-- .element: class="fragment" -->

* *graceful/disgraceful*
* *spectacle/spectacles*
* *new/news*
* *hard/hardly*

## Compounding

English **bases** are compounded together.

<!-- .element: class="fragment" -->

@table widths=30,70
| | |
|---|---|
| *hovercraft* | {answer *hover + craft*} |
| *bonfire* | {answer *bone + fire*} |
| *holiday* | {answer *holy + day*} |
| *woman* | {answer *wife + man*} |
| *goodbye* | {answer *god + be + with + ye*} |
| *lord* | {answer *loaf + ward*} |
| *hussy* | {answer *house + wife*} |
